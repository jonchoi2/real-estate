# 신봉 동일하이빌 매물 보드

용인시 수지구 신봉동 동일하이빌 2·3·4단지 매매 매물을 한눈에 비교하는 공개 페이지입니다.

- 2026-09-06 네이버 58건, KB 전체 집계 59건, 아실 4단지 광고 3건 확인
- 제외 요청한 8개 비교 묶음과 개인 메모를 제거하고 26개 묶음 표시
- 표시 광고: 네이버 47건 / KB 48건 / 아실 3건 (서로 중복되므로 합산 금지)
- 네이버 개별 광고 또는 단지 목록, KB, 아실 원문 링크 제공
- 아실에서 확인한 면적별 최근 매매 사례 18건을 호가와 분리 표시
- 단지 필터와 가격/동 정렬 제공

> 매물은 수시로 바뀝니다. 이 저장소의 데이터는 페이지에 표시된 기준일의 스냅샷이며, 계약 전 중개사와 최신 상태를 다시 확인해야 합니다.

데이터는 app/data.ts, 실거래 사례는 app/trades.ts에 있습니다. 동·가격·면적이 비슷한 비교 묶음이지 동일 호수가 확인된 집 수는 아닙니다. KB 면적별 집계는 제외 전 단지 전체 수치입니다. 아실 실거래 표는 전체 역사 데이터가 아닌 확인 사례입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

`main` 브랜치에 푸시하면 GitHub Pages 배포 워크플로가 실행됩니다.
