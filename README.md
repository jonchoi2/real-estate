# 신봉 동일하이빌 매물 보드

용인시 수지구 신봉동 동일하이빌 2·3·4단지 매매 매물을 한눈에 비교하는 공개 페이지입니다.

- 포털 광고 58건을 동·가격·층 기준 30개 후보군으로 묶어 표시
- 사용자가 직접 확인한 매도자·임차 조건과 임장 일정을 포털 정보에 병합
- 네이버부동산 개별 광고 또는 단지 매물 목록, KB부동산 단지 페이지로 연결
- 단지 필터와 가격/동 정렬 제공

> 매물은 수시로 바뀝니다. 이 저장소의 데이터는 페이지에 표시된 기준일의 스냅샷이며, 계약 전 중개사와 최신 상태를 다시 확인해야 합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

`main` 브랜치에 푸시하면 GitHub Pages 배포 워크플로가 실행됩니다.
